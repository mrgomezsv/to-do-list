# Todo List

Este es un proyecto de una lista de tareas (Todo List) desarrollada en HTML, CSS y JavaScript.

## Descripción

La aplicación permite a los usuarios agregar, eliminar y visualizar tareas pendientes. El objetivo es proporcionar una interfaz simple y funcional para gestionar tareas diarias.

## Estructura del Proyecto

El proyecto está compuesto por los siguientes archivos y carpetas:

- `index.html`: El archivo principal de la aplicación.
- `assets/`: Carpeta que contiene los recursos estáticos.
  - `style/style.css`: Hoja de estilos para la aplicación.
  - `img/favicon.jpg`: Imagen de perfil utilizada en la aplicación.
  - `script/script.js`: Script de JavaScript para la funcionalidad de la lista de tareas.

## Uso

1. Abre el archivo `index.html` en tu navegador web.
2. En la sección de la lista de tareas, introduce el título y la descripción de una nueva tarea.
3. Haz clic en el botón "Agregar" para añadir la tarea a la lista.
4. Las tareas se mostrarán en la lista debajo del formulario de entrada.
